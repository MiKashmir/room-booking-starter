# ADR 0001: Зберігання бронювань у пам'яті процесу

## Контекст
Системі потрібно зберігати стан бронювань аудиторій між запитами. Проєкт розробляється для тестування та демонстрації API.

## Розглянуті варіанти
* Зберігання в оперативній пам'яті (in-memory масив).
* Запис у файлову систему (наприклад, JSON).
* Підключення бази даних.

## Рішення
Обрано зберігання бронювань в оперативній пам'яті процесу (in-memory масив).

## Обґрунтування
Оскільки це базова версія сервісу, in-memory масив дозволяє уникнути зайвої складності з налаштуванням БД та забезпечує максимальну швидкість обробки запитів.

## Наслідки
* **Позитивні:** Максимальна продуктивність, відсутність зовнішніх залежностей.
* **Негативні:** Усі дані про бронювання безповоротно втрачаються при перезапуску сервера. Масштабування сервісу на кілька серверів неможливе.
