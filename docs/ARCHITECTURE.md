# Архітектура room-booking

## Рівень 1: Контекст
Сервіс призначений для викладачів та адміністрації коледжу, які бронюють аудиторії для занять і заходів. Початковий перелік аудиторій завантажується зі статичного файлу `data/rooms.json`. Дані про бронювання тимчасово зберігаються в пам'яті процесу під час роботи сервера.
