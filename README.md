# room-booking

## 1. Короткий опис проєкту

`room-booking` — Node.js-застосунок на Express, що надає HTTP API для перегляду аудиторій, роботи з бронюваннями та пошуку вільних часових проміжків. Початковий перелік аудиторій завантажується з `data/rooms.json`.

Система використовується для управління розкладом аудиторій коледжу. Дозволяє викладачам та адміністрації швидко знаходити вільні кабінети та бронювати їх для занять або заходів.

## 2. Передумови

- Node.js і npm. Потрібну або рекомендовану версію Node.js не вказано: Рекомендована версія Node.js — 18.x LTS або новіша.
- Для розробки та тестування — npm і пакети з `package.json`.

## 3. Встановлення

У кореневому каталозі проєкту виконайте:

```bash
npm install
```

Файл `.env.example` містить приклад значень змінних середовища:

```dotenv
PORT=3000
MAX_BOOKING_HOURS=4
```

Перед запуском задайте потрібні змінні у своєму середовищі. Наприклад, у PowerShell:

```powershell
$env:PORT = "3000"
$env:MAX_BOOKING_HOURS = "4"
```

`package.json` не містить залежності для автоматичного завантаження `.env`, тому копіювання `.env.example` у `.env` саме по собі не встановлює змінні середовища для Node.js.

## 4. Запуск і перевірки

Запустити застосунок:

```bash
npm start
```

Сервер слухає порт зі змінної `PORT`; якщо її значення відсутнє, дорівнює `0` або не перетворюється на число, використовується порт `3000`. Після запуску адреса виводиться в консоль.

Запустити тести:

```bash
npm test
```

Додаткові команди з `package.json`:

```bash
npm run docs:check
npm run docs:html
```

`docs:check` перевіряє типи та ESLint для `src`, а `docs:html` генерує документацію JSDoc згідно з `jsdoc.json`.

## 5. Основні конфігурації

| Змінна | Призначення | Значення за замовчуванням |
|---|---|---|
| `PORT` | Порт HTTP-сервера | `3000` |
| `MAX_BOOKING_HOURS` | Максимальна тривалість одного бронювання в годинах | `4` |

Бронювання зберігаються в пам'яті процесу: після перезапуску сервера вони не зберігаються. Мінімальний час до початку бронювання, коли його ще можна скасувати, становить 12 годин

## HTTP API

| Метод | Шлях | Опис |
|---|---|---|
| `GET` | `/api/rooms` | Повертає перелік аудиторій. |
| `GET` | `/api/rooms/:id/bookings?date=YYYY-MM-DD` | Повертає бронювання аудиторії за датою. |
| `GET` | `/api/rooms/:id/free?date=YYYY-MM-DD&min=45` | Повертає вільні проміжки на дату; `min` — мінімальна тривалість у хвилинах, за замовчуванням `45`. |
| `POST` | `/api/bookings` | Створює бронювання. |
| `DELETE` | `/api/bookings/:id` | Скасовує бронювання. |

Тіло запиту `POST /api/bookings` має містити поля `roomId`, `date`, `from`, `to` та `who`. Час задається у форматі `HH:mm`. Для помилок API повертає JSON з полем `error`.

## Структура проєкту

```text
.
├── data/
│   └── rooms.json       # Початковий перелік аудиторій
├── src/
│   ├── app.js           # Налаштування Express та API-маршрути
│   ├── bookings.js      # Створення, перегляд і скасування бронювань
│   ├── server.js        # Запуск HTTP-сервера
│   ├── slots.js         # Перетини бронювань і пошук вільних проміжків
│   └── time.js          # Перетворення часу
├── tests/
│   ├── api.test.js      # Тести API
│   └── slots.test.js    # Тести часових проміжків
├── .env.example         # Приклад змінних середовища
├── CHANGELOG.md         # Історія змін
├── eslint.config.js     # Конфігурація ESLint
├── jsconfig.json        # Конфігурація перевірки JavaScript
├── jsdoc.json           # Конфігурація JSDoc
├── README.md            # Документація проєкту
└── package.json         # Метадані, залежності та npm-команди
```
